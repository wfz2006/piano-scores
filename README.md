# 周杰伦钢琴谱 · MusicXML / MIDI

三首周杰伦钢琴独奏谱由 PDF 谱面转换而来，每首提供三种格式：

| 文件 | 说明 |
| --- | --- |
| `*.musicxml` | MusicXML 4.0 Partwise，推荐主用 |
| `*.xml` | 与 `.musicxml` 内容完全一致，仅为兼容只认 `.xml` 后缀的软件 |
| `*.mid` | Standard MIDI File（Format 1），供 DAW / 播放器使用 |

## 曲目

| 曲目 | 小节数 | 速度 | 调号 | 拍号 |
| --- | --- | --- | --- | --- |
| 给我一首歌的时间 | 122 | 118 BPM | 降D大调 → 第 97 小节转 D 大调 | 4/4 |
| 夜的第七章（完美独奏版） | 80 | 见文件内速度标记 | 见文件内调号 | 4/4 |
| 青花瓷（精编简易版） | 69 | 96 BPM | C 大调 | 4/4 |

## 使用方法

- 记谱软件：MuseScore、Dorico、Sibelius、Finale、Logic Pro 均可直接打开 `.musicxml`。
- 播放 / 编曲：把 `.mid` 拖入 DAW，音色为 Acoustic Grand Piano（Program 1）。
- 浏览器预览：可用 OpenSheetMusicDisplay、Verovio 等渲染 MusicXML。

## 说明

- 谱面由 PDF 自动识别生成，音符、时值、调号、谱号已做结构校验，但细微的连奏、力度、踏板等演奏记号可能不完整。
- 建议对照原谱听一遍再使用；如需逐小节精修，欢迎提 Issue。
